# az400-lab

Mini app Node.js (zero dipendenze) usata per gli esercizi di laboratorio AZ-400.

```bash
npm test      # esegue i test (node:test)
npm start     # avvia il server su :3000
```

Endpoint: `/` (saluto), `/health` (JSON `{"status":"ok"}`).
